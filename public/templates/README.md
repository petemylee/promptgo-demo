# PDF Templates Directory

โฟลเดอร์นี้ใช้สำหรับเก็บไฟล์ PDF template สำหรับการสร้างเอกสาร

## ไฟล์ที่ควรมี:

### 1. `booking-approval-template.pdf`
- Template สำหรับเอกสารอนุมัติการเดินทาง
- ควรมีช่องว่างสำหรับเติมข้อมูล:
  - ชื่อผู้ขอใช้
  - อีเมล
  - วัตถุประสงค์
  - สถานที่เริ่มต้น/ปลายทาง
  - วันเวลา
  - ข้อมูลรถและคนขับ
  - พื้นที่ลายเซ็น

## วิธีการใช้งาน:

1. อัปโหลดไฟล์ PDF template มาที่นี่
2. ระบบจะใช้ template นี้ในการสร้างเอกสารอนุมัติ
3. หากไม่มี template ระบบจะสร้าง PDF ใหม่โดยอัตโนมัติ

## หมายเหตุ:

- ไฟล์ template ควรเป็น PDF ที่มีช่องว่างสำหรับเติมข้อมูล
- ขนาดไฟล์ไม่ควรเกิน 10MB
- ควรทดสอบการสร้างเอกสารหลังจากอัปโหลด template ใหม่
