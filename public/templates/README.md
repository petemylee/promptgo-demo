# PDF Templates Directory

โฟลเดอร์นี้ใช้สำหรับเก็บไฟล์ PDF template สำหรับการสร้างเอกสาร

## ไฟล์ที่ควรมี:

### 1. `booking-approval-template.pdf`
- Template สำหรับเอกสารอนุมัติการเดินทาง
- ควรมีช่องว่างสำหรับเติมข้อมูลตามตำแหน่งที่กำหนดไว้

### 2. `template-coordinates.md`
- คู่มือตำแหน่งที่แนะนำสำหรับใส่ข้อมูลใน template
- ใช้เป็นแนวทางในการออกแบบ template

## วิธีการใช้งาน:

1. **วาง Template:** อัปโหลดไฟล์ PDF template มาที่นี่
2. **ตรวจสอบตำแหน่ง:** ดูไฟล์ `template-coordinates.md` เพื่อทราบตำแหน่งที่แนะนำ
3. **ทดสอบ:** ระบบจะใช้ template นี้ในการสร้างเอกสารอนุมัติ
4. **ปรับแต่ง:** หากต้องการเปลี่ยนตำแหน่ง ให้แก้ไขในไฟล์ API

## รูปแบบข้อมูลที่ระบบจะใส่:

```
วันที่: [วันที่สร้างเอกสาร]
ชื่อ: [ชื่อผู้ขอใช้]
ตำแหน่ง: [ตำแหน่งงาน]
ใช้รถยนต์ไป[สถานที่ปลายทาง]
เพื่อ[วัตถุประสงค์]
ในวันที่[วันที่และเวลาที่เดินทาง]

รถยนต์: [ยี่ห้อ] [รุ่น] ([หมายเลขทะเบียน])
คนขับ: [ชื่อคนขับ]

อนุมัติโดย: [ชื่อผู้ดูแลระบบ]
ยืนยันโดย: [ชื่อผู้บริหาร]
[ลายเซ็น]
```

## หมายเหตุ:

- ไฟล์ template ควรเป็น PDF ที่มีช่องว่างสำหรับเติมข้อมูล
- ขนาดไฟล์ไม่ควรเกิน 10MB
- ควรทดสอบการสร้างเอกสารหลังจากอัปโหลด template ใหม่
- หากไม่มี template ระบบจะสร้าง PDF ใหม่โดยอัตโนมัติ

## การปรับแต่งตำแหน่ง:

หากต้องการเปลี่ยนตำแหน่งการใส่ข้อมูล ให้แก้ไขไฟล์:
`src/app/api/bookings/[bookingId]/pdf/route.ts`

ในส่วนของ `page.drawText()` และ `page.drawImage()`
